Lesson 0001 · CNN · No.10–12

看见 CNN 学到了什么

准确率只告诉你“答对多少”，卷积核、特征图和错误样本才开始回答“模型为什么这样答”。本课对应 MNIST 项目从能训练到能解释的下一步。

1. 卷积核：模型学到的局部检测器

第一层 Conv2d(1, 16, 3) 的权重 shape 是 (16, 1, 3, 3)：16 个独立的卷积核，每个核读取 1 个输入通道中的 3×3 邻域。每个核在整张图上复用，产生一张输出特征图。PyTorch 的定义明确把输入写成 (N, C_in, H, W)，输出写成 (N, C_out, H_out, W_out)；每个输出通道都会对所有输入通道做加权求和。官方 Conv2d 文档

# 训练后查看第一层的 16 个卷积核
kernels = model[0].weight.detach().cpu()  # (16, 1, 3, 3)
print(kernels.shape)
别把卷积理解成“修复中心像素”。输出值是某个局部模式的响应强度。16 个核对同一邻域做 16 种不同加权计算，所以 1 个灰度通道会变成 16 个特征通道。

2. 特征图：卷积核在具体数字上发现了什么

卷积核是参数；特征图是参数作用到一张图片后的结果。同一个核面对“1”和“8”会产生不同响应。第一层输出 (1, 16, 28, 28)，意味着一张图得到 16 张响应图。

image, label = next(iter(test_loader))
image = image[:1]

with torch.no_grad():
    before_relu = model[0](image)       # (1, 16, 28, 28)
    after_relu = model[1](before_relu)  # 负响应被截为 0

print(before_relu.shape, after_relu.shape)

对照卷积前、ReLU 后、池化后的图，分别观察“检测到了什么”“哪些响应被保留”“空间位置怎样被压缩”。官方 CNN 分类教程展示了卷积、池化、展平与全连接的标准数据流。官方 Training a Classifier 教程

3. 错误样本：解释 CNN 比 MLP 好在哪里

总体准确率把所有样本压成一个数字。更有解释力的是把样本分成四组：

两者都对
容易样本，不帮助区分模型。
MLP 错、CNN 对
重点观察位置偏移和局部笔画。
MLP 对、CNN 错
寻找 CNN 新引入的失败模式。
两者都错
可能是模糊、歧义或数据本身困难。

真正的问题不是“CNN 多对了多少”，而是“它多对的那些图有什么共同结构”。

5 分钟练习

  2. 选一张数字，预测哪类局部位置会在 ReLU 后保持亮响应。
  3. 从“MLP 错、CNN 对”中挑 10 张，写出一个共同特征假设。
核对第 1 题

(16, 1, 3, 3)。16 是输出通道，1 是输入通道，后两个 3 是卷积核高和宽。
